Write a program that prints **Hello, World!** to the screen.

This is the classic first program that every programmer writes. It teaches you:
- How a C++ program is structured
- How to use `cout` to display text
- How to use `endl` to create a new line

Your output should be exactly:
```
Hello, World!
```
