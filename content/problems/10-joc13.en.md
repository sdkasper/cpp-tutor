Two children want to play a game with two pieces and a board consisting of `N` squares numbered from `1` to `N`, arranged one after another in a line. The game has the following rules:

- the pieces are placed on the first square of the board (each child has their own piece);
- the first child is the one who starts the game;
- the children take turns at the board;
- the player whose turn it is makes, according to the rule below, one or more moves before yielding to the other: they calculate a value `X` as described below; they move their piece forward by `X` positions, and if the calculated value `X` is `6`, they have the right to calculate another value `X`, thus making another move without yielding to the other child yet; if `X` is different from `6`, they yield their turn;
- `X` is calculated by the rule: if the move number is odd then: `X=((move_number + ((piece_square_number + N) mod 10)) mod 6) + 1`, and if the move number is even then: `X=((((move_number+1) mod 5) + ((piece_square_number + N) mod 10)) mod 6) + 1`
	where `N` is the number of squares on the board, `move_number` means which move this is, `mod` is the operation that yields the remainder of integer division, and the resulting value `X` is one of the digits `1`, `2`, `3`, `4`, `5`, or `6`, as can be deduced from the formulas above.
- after advancing, if a piece lands on a square currently occupied by the other piece, it takes its place, and the piece that was there is sent back to square `1` (this return to position `1` is not counted as a move);
- if a piece, after advancing, would go beyond the board, it is placed on square `N` (the last);
- the winner is the child who first reaches square `N` with their piece, and then the game ends.

## Task

Given the number `N`, determine:

- The number of divisors of `N`;
- The maximum number of occurrences of a value calculated during the game using the described formulas;
- The square numbers occupied during the game by the winner's piece, in the order they were visited.

## Input Data

The first line of the file `joc.in` contains two natural numbers, `C` and `N`, separated by a space. If `C=1`, only the first task is solved; if `C=2`, only the second task is solved; if `C=3`, only the third task is solved.

## Output Data

The output file is `joc.out`. If `C=1` or `C=2`, it contains a natural number representing the answer for the respective task. If `C=3`, it contains a sequence of natural numbers, separated by spaces, representing the answer for the third task.

## Constraints and Notes

- `2 ≤ N ≤ 10,000`
- For tests worth `23` points, `C=1`
- For tests worth `33` points, `C=2`
- For tests worth `44` points, `C=3`
- It is guaranteed that there is a winner
- During the game, children may visit squares they have previously visited
- It is guaranteed that the number of squares occupied by children is less than `100,000`
- The problem does not aim to find any special property of the value sequences calculated by the given formulas.

## Example 1:

`joc.in`

```
1 10
```

`joc.out`

```
4
```

### Explanation

`C=1`, so the first task is solved. `N=10` has `4` divisors.

## Example 2:

`joc.in`

```
2 10
```

`joc.out`

```
2
```

### Explanation

`C=2`, so the second task is solved. Both pieces are on square 1. The first child moves (their piece is on square `1`).

- we are at the first move (odd number);
- the advance digit is calculated: `X = (1 + (1 + 10) mod 10) mod 6 + 1 = 3`
- the first player advances from square `1` to square `4`

The second child moves (their piece is on square `1`)

- we are at the second move (even number);
- the advance digit is calculated: `X = ((((2 + 1) mod 5) + ((1+10) mod 10)) mod 6) + 1 = 5`
- the second child advances from square `1` to square `6`

The first child moves (their piece is on square `4`)

- we are at the third move (odd number);
- the advance digit is calculated: `X= (3 + (4 + 10) mod 10) mod 6 + 1 = 2`
- the first child advances from square `4` to square `6`
- since the second child's piece is on square `6`, it is sent back to the first square, so the second child's piece now occupies square `1`

The second child moves (their piece is on square `1`)

- we are at the fourth move (even number);
- the advance digit is calculated: `X = ((4 + 1) mod 5 + (1 + 10) mod 10) mod 6 + 1 = 2`
- the second child moves from square `1` to square `3`

The first child moves (their piece is on square `6`)

- we are at the fifth move (odd number);
- the advance digit is calculated: `X = (5 + (6 + 10) mod 10) mod 6 + 1 = 6`
- the first child moves from square `6` to square `10` (it should have moved to square `12` which is beyond the board)
- the digit is `6`, the child has the right to another move but has already reached the final square and the game ends.

The first child is the winner. The calculated digits were, in order, `3` `5` `2` `2` `6`; the digit `2` appeared the most times, namely `2` times.
