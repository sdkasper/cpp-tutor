Given `N` natural numbers that contain in their decimal representation only digits from the set `{0, 1, 2, 3, 4}`. A number is called special if it contains at least one odd digit and each odd digit appears an even number of times.

## Task

1. Calculate the number of special numbers in the given array.
2. Calculate the number of contiguous subsequences of length `<= K` that contain exactly one special number.
3. For each contiguous subsequence of length `K`, determine the minimum number of elements that must be removed so that the concatenation of the remaining elements produces a special number, or output `-1` if it is impossible.

## Input Data

In the input file `p13.in`, the first line contains, separated by spaces, `C`, `N`, and `K`, where `C` is the task (`1`-`3`), `N` is the number of values, and `K` is the required length. The second line contains `N` numbers separated by spaces.

## Output Data

In the output file `p13.out`, the first line will contain the value obtained for tasks 1 and 2, and for task 3 the obtained values will be displayed separated by spaces.

## Constraints and Notes

- `1 <= C <= 3`
- `1 <= K <= N <= 100,000`
- Each number contains at most 6 digits
- For 21 points, `C = 1`
- For 40 points, `C = 2`
- For 39 points, `C = 3`

## Example 1

`p13.in`

```
1 4 3
121 423 43 3003
```

`p13.out`

```
2
```

### Explanation

The special numbers are `121` and `3003`.

## Example 2

`p13.in`

```
2 4 3
121 423 43 3003
```

`p13.out`

```
6
```

### Explanation

Six subsequences contain exactly one special number: `121`; `121 423`; `121 423 43`; `3003`; `43 3003`; `423 43 3003`.

## Example 3

`p13.in`

```
3 4 3
121 423 43 3003
```

`p13.out`

```
0 0
```

### Explanation

Both sequences of length `K` become special numbers when concatenated: `12142343` and `423433003`.
