Se dau `N` numere naturale care contin in scrierea lor doar cifre din multimea `{0, 1, 2, 3, 4}`. Un numar se numeste special daca contine cel putin o cifra impara si fiecare cifra impara apare de un numar par de ori.

## Cerinta

1. Calculati numarul de numere speciale din sirul dat.
2. Calculati numarul de subsecvente de lungime `≤ K` care contin exact un numar special.
3. Pentru fiecare subsecventa de lungime `K`, determinati numarul minim de elemente care trebuie eliminate astfel incat concatenarea elementelor ramase sa produca un numar special, sau afisati `-1` daca este imposibil.

## Date de intrare

In fisierul de intrare `p13.in` se gasesc pe prima linie, separate prin cate un spatiu, `C`, `N` si `K`, unde `C` este cerinta (`1`-`3`), `N` este numarul de valori, iar `K` este lungimea ceruta. Pe a doua linie se afla `N` numere separate prin cate un spatiu.

## Date de iesire

In fisierul de iesire `p13.out` se va scrie pe prima linie valoarea obtinuta pentru cerintele 1 si 2, iar pentru cerinta 3 se vor afisa valorile obtinute separate prin cate un spatiu.

## Restrictii si precizari

- `1 ≤ C ≤ 3`
- `1 ≤ K ≤ N ≤ 100.000`
- Fiecare numar contine cel mult 6 cifre
- Pentru 21 de puncte, `C = 1`
- Pentru 40 de puncte, `C = 2`
- Pentru 39 de puncte, `C = 3`

## Exemplul 1

`p13.in`

```
1 4 3
121 423 43 3003
```

`p13.out`

```
2
```

### Explicatie

Numerele speciale sunt `121` si `3003`.
